02 — What

A full mirror, within a filter scope

CreateIn scope on source, missing on shadow → created with members
UpdateMembership differs → overwritten to match the source
DeleteOn shadow but gone from source → removed

In scope, the source is authoritative

Add a member directly on the shadow → stripped on the next sync. Delete an in-scope role on the shadow → recreated.

Roles outside the filter are never read, created, modified, or deleted. The filter is your blast-radius control.

Redpanda → Redpanda only Non-Redpanda source: task parks, rest of the link unaffected (next slide).
Credentials are not synced — by design Pre-provision identities on the shadow; role sync mirrors membership.
Opt-in Empty filters → nothing syncs. The task stays ACTIVE and does nothing.

03 — How

One new Kafka API, in a reserved range

Shadow clusterroles migrator task
DescribeRedpandaRoles · key 15000 over the source's Kafka listener
Source clusterRedpanda 26.2+
Nothing standard to read Roles aren't in the Kafka data model — its security surface is ACLs, SCRAM, tokens, quotas.
Why a Kafka API The Admin API isn't reachable cross-cluster and isn't exposed in BYOC. The Kafka listener is the surface the link already uses.
Zero new permissions Authorized by cluster DESCRIBE — the same gate as DescribeAcls, which the link principal already holds.
Consequence: Apache Kafka / Confluent sources can't answer key 15000 → the role-sync task parks LINK_UNAVAILABLE; topic, ACL, and schema registry sync continue untouched. Role shadowing is Redpanda↔Redpanda DR.

04 — Opting in

Filters are the blast-radius control

name: prod-shadow-link
# …topic / consumer / security sync options…
role_sync_options:
  interval: 30s
  role_name_filters:
    - pattern_type: LITERAL
      filter_type: INCLUDE
      name: '*'  wildcard: every role
Empty filters → nothing syncs. Role sync is opt-in: at least one INCLUDE.
LITERAL '*' is the only wildcard. Under PREFIX, * is just a character.
In scope, the source is authoritative. Created, updated — and deleted — to match the source.
